# Daily work

**Describe the work, let your agent do it, decide the result.**

1. [Create a ticket](/daily-work/create-a-ticket): tell your agent what you need.
2. [Follow a ticket](/daily-work/follow-a-ticket): read the summaries and answer questions.
3. [Accept results](/daily-work/accept-results): check the work and give your OK.
4. [Record time](/daily-work/record-time): review the hours your agent proposes and save them.

Want an email when a ticket changes? [Set up notifications](/daily-work/email-notifications). Need to pause a ticket? [Freeze it](/daily-work/freeze-a-ticket). Working in the browser? [Use claude.ai](/daily-work/claude-ai).

::: tip Ask your agent
Read this project's workflow, help me sharpen my requirement and create a ticket with clear acceptance criteria.
:::

How each step works is explained in [Skills & Workflows](/skills-and-workflows/).
