# Contributing to bakers.build

These guides concern changes to bakers.build itself. Use a source checkout matching your release and read its `CLAUDE.md`, `WORKFLOW.md` and `docs/bakers/` conventions before changing implementation. Repository access is required for the detailed guides; your operator can provide the matching source. User extensions belong in [Addons](/addons/build/contracts) and [workflow recipes](/configuration/workflows/recipes).
