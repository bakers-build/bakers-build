# `qualification` template

```markdown
## Acceptance

- **AC1:** <an intake's criterion word for word; else: As a <role>, I want <behaviour>, so that <benefit>.>

## Out of scope

- <boundary>

## Handoff metadata

| Field | Value |
|---|---|
| `recipe` | the recipe's name and why it fits |
| `ticket_type` | `feature`, `bug` or `chore` |
| `reproduction` | the bug's condition, else `not_required` |
| `scenario_required` | `true` for a browser path, else `false` |
| `test_as` | who tests and what each sees, or `no login needed` |
| `prior_art` | each searched term and its outcome |
| `handoff_version` | `1` |
```
