# Retrospective evidence

Read only for causes the human named. Pair each human statement with a counted fact or explicit
limitation printed directly below it; distinguish statement from inference. Read relevant
handoffs, recipe and agent labels. Query `bakers_ticket_runs_list` via [tools](tools.md), following
next_offset to null before exact counts. Partial/denied reads mean unavailable, not zero.
Tickets have no queryable transition history; use state_at_start and agent on runs.

- coding_loops: count working-start runs, name it working-run count, not proven review bounces
  (retries also count). Compare coding/review handoffs for rework.
- model_fit: pair named step with the agent that actually ran. Routing labels prove intent only,
  not execution or model suitability.
- spec_quality/review_information: compare applicable spec/plan/test or review handoff with the
  account; quote/link omission/correction. If not quantifiable: **No direct measurement**.
- other: give observable counterpart only if present; else **No direct measurement**.

No named causes means no evidence queries; do not copy a general footprint report.
