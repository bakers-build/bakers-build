# Outtake

Read state section: [qualification](outtake/qualification.md), [plan](outtake/plan.md),
[working](outtake/working.md), [review](outtake/review.md).
Render English handoff/[results](results.md) once; print/publish identical summary before questions. Supplied facts only; name missing values. State owns writes.

Headings in order; omit empty optional sections:

### 🎯 Outcome

Ticket, change and reason in 1–2 sentences; distinguish delivery/proposal. State lead follows.

### ✅ Success

Executed/reused results; unrun is no pass.

### ⚠️ Problems

Failed/blocked/unresolved: AC, expected/observed, impact/evidence, repair/decision. Include supplied
criterion rewrites; distinguish proposed/completed repairs.

### 🧪 Manual review

Human steps/view, persona/environment, MR/surfaces/designs/artifacts/commands (cwd/access).
Keep denied/missing personas; agent inspection is no human approval.
From working, missing MR fails run. Links: 🔗, label, blank lines, each URL once; verified HTTPS
([evidence](evidence.md)), no pipelines. Preserve login URLs with persona/role/environment (access only). Local surfaces use [preview links](preview-links.md).
Recipe type outtake slot (else general) appends without heading; absent values: `not recorded`.

### ➡️ Next action

One action/decision. Full evidence stays typed.
