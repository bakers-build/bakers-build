# Evidence and links

Comment evidence: [ticket writes](ticket-writes.md); retain MR/permanent tests.
Transient logs/reports/probes: gitignored `assets-ai/<identifier>/`, removed with worktree.
Permanent tests: behavior names; transient probes: ticket names. Inspect tests before staging.
Use lowercase binary directories, kinds only for multiple outputs ([browser](browser.md)).
Name subject/red/green/review; output starts with command, SHA inside; repeats overwrite.
MR links, never pipeline links; preserve human links. Local artifacts: absolute file:// URLs;
external: absolute URLs. [Outtake](outtake.md) formats visible resources.
