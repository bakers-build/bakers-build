# Selected setup checks

Preserve the selected scope and every path override. Read CLI findings with owning file/key,
fingerprint, remedy and recheck command. Machine validity is local; connection readiness requires
authentication, with workspace optional. Project readiness requires both independently.
Use `--secret-env` for credentials, never print secrets. The CLI owns transformations and backups;
unsupported rewrites/conflicts preserve files and report a concrete limitation. Cross-scope changes
require authorized `all` scope. Recheck local validity and then selected connection authentication;
prepared files alone are not readiness.
