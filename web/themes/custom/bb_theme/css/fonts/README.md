# Theme fonts

Self-hosted Latin variable WOFF2 fonts of the CI, including German umlauts and
ß. Normal weights are supplied by the variable font; italic uses browser
synthesis.

- `spline-sans.woff2`: text. `@fontsource-variable/spline-sans@5.3.0` from
  https://fontsource.org/fonts/spline-sans. License: `spline-sans.LICENSE`.
- `spline-sans-mono.woff2`: machine values (keys, branches, IDs).
  `@fontsource-variable/spline-sans-mono@5.3.0` from
  https://fontsource.org/fonts/spline-sans-mono. License:
  `spline-sans-mono.LICENSE`.
- `bricolage-grotesque.woff2`: page titles only.
  `@fontsource-variable/bricolage-grotesque@5.3.0` from
  https://fontsource.org/fonts/bricolage-grotesque. License:
  `bricolage-grotesque.LICENSE`.
